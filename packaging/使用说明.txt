声纹解锁 VoiceUnlock —— 使用说明
================================================================

一句话
    锁屏时，正常说一句话就能进桌面，不用敲密码。密码框仍在，随时可当后备。


怎么用
    1. 按 Win+L 锁屏。
    2. 对着麦克风正常说一句 2~5 秒的话（不用喊，不用刻意说满）。
    3. 2~10 秒后自动进入桌面。

    注意：解锁需要 2~10 秒，取决于你说话的时刻正好落在系统的哪个轮询周期里。
    **锁屏界面上不会有任何提示**（我们的设计就是界面上不出现任何东西），
    所以请耐心等一会儿，不要连按回车 —— 也**不会有"提示音"**。


第一次使用前必须做的一件事
    声纹解锁最终要"替你交密码"，所以程序必须知道你 Windows 登录密码。
    安装时如果勾选了「安装完成后立即设置登录凭据」，按提示输入即可；
    没勾选的话，从开始菜单运行「设置登录凭据」。

    密码只保存在本机，用 Windows 自带的 DPAPI（用户作用域）加密，
    只有你自己的登录会话能解开。它不会以明文出现在任何文件或日志里。


登记声纹（要念什么）
    从开始菜单运行「登记声纹」，屏幕上会打出【要你朗读的那句话】，
    倒计时结束后照着念一遍就行 —— 一次连续录 8 秒，不用反复配合。

        --------------------------------------------------------------
        准备录音 —— 这一段要录 8.1 秒
        请朗读下面这句话（正常语速，不用刻意拖长，也别太急）：

            今天天气不错，我打算下午出去走一走，顺便去超市买点水果和牛奶，
            回来的时候把楼下的快递一起取上来。

             5 ...  4 ...  3 ...  2 ...  1 ...
             ==> 现在开始说！
        --------------------------------------------------------------

    念什么内容其实不影响识别（声纹与文本无关），给句子只是让你知道
    "现在该说话了、要说多久"。正常语速、别停顿太久即可。

    想给多支麦克风都登记，用命令行 --all（每台录 3 遍，每一遍都会给出
    要念的句子）；只想给常用的那一支登记，用 --device <序号>。
    其实不登记也能用：任何一次成功解锁之后，用到的设备会被自动建档。


换麦克风 / 新插设备
    都能用。程序会自动枚举所有语音输入设备（包括新插入的），
    并在你成功解锁一次之后，自动为那个设备建立声纹档案 —— 下一次它就是"一等公民"。


排障（先跑这一条）
    开始菜单 →「查看状态（排障）」，或命令行：
        VoiceUnlock.exe paths

    重点看这几行：
        凭据可读性    = OK     ← 如果是 ✗，说明当前登录会话解不开凭据，
                                  重跑一次「设置登录凭据」即可（会解释原因）
        ONNX 模型     = (存在)
        声纹档案数    = 1 以上
        CP 注册状态   = 两处齐全（present）
        登录自启      = 计划任务 VoiceUnlockAgent（最高权限）  ← 见下面的说明

    ★ 关于「登录自启」：新版**不再写 HKCU Run**，改成**计划任务**
      （任务名 VoiceUnlockAgent，登录时触发，运行级别=最高权限）。
      为什么必须这样（这不是随手改的）：
        agent 的命名管道有"对端校验"，要读锁屏进程（LogonUI.exe，SYSTEM 身份）
        的映像名。**普通权限**下 OpenProcess 会被系统拒绝（err=5），
        取不到映像 → 所有锁屏请求都被判 peer-not-allowed → 声纹再准也不解锁。
        实测症状：agent.log 里几百行「拒绝对端（映像='?'）」，而收到的请求一条都没有。
      如果你在旧版升上来，旧的 HKCU Run 项会被自动删掉 —— 因为两个实例
      会抢同一个管道名，而且那个普通权限实例根本做不了对端校验。
      （旧版提示的"登录自启 = 未登记"就是这么来的：它只检查 HKCU Run。）

    日志：
        %LOCALAPPDATA%\VoiceUnlock\logs\agent.log
        （每次判定、分数、阈值、耗时都在里面；对端被拒的日志做了限流，
          不会再把日志刷满）

    提示：程序会按系统语言自动选输出语言 —— 中文 Windows 显示中文，
    其它语言的 Windows 显示英文（那种机器的控制台是 437 代码页，中文会变乱码）。
    想强制指定：set VOICEUNLOCK_LANG=zh  （或 en）之后再跑命令。


卸载
    控制面板 → 程序和功能 → 声纹解锁。
    卸载会【先注销锁屏凭据提供者，再删除文件】，并删除你的凭据与声纹数据
    （那是加密口令和生物特征，不该留在磁盘上）。


紧急退出（请务必读一遍）
    声纹解锁会"接管锁屏"，所以下面几条退路请至少记住一条。

    [A] 最常用：锁屏上的密码框一直都在，而且界面上【没有我们的任何东西】
        Windows 自带的密码登录项（PasswordProvider）从未被移除，锁屏界面
        也从未被改动：不额外画磁贴、不加状态文字、不改外观。
        正常情况下你看到的就是 Windows 原样的登录界面。
        只有一种情况会看到变化：声纹判定通过、解锁票据已经备好的那一刻，
        Windows 会自己做一次自动提交 —— 那就是"进了桌面"，不需要你点任何东西。
        任何时候想手输密码：直接输就行（Ctrl+Alt+Del 也随时可用）。

    [B] 已经进了桌面、想立刻关掉它
        双击桌面上的「★ 紧急关闭声纹解锁」（开始菜单里也有一个）。
        它会弹一次 UAC，然后做完三件事：注销锁屏凭据提供者、停掉常驻监听、
        移除登录自启。做完之后锁屏就是 Windows 原来的样子。
        等价的手工做法（管理员身份）：
            VoiceUnlock.exe panic

    [C] 最保险的保底：WinRE（连桌面都进不去时用）
        本机 BitLocker 是关闭的，所以不涉及恢复密钥。步骤：
          1. 用 Windows 安装 U 盘启动 → 选「修复计算机」→「疑难解答」→
             「高级选项」→「命令提示符」；
          2. 先确认 Windows 装在哪个盘（一般是 C:）：
                 dir C:\Windows\System32\config
          3. 挂载注册表并删掉声纹解锁的两处注册项：
                 reg load HKLM\OFF C:\Windows\System32\config\SOFTWARE
                 reg delete "HKLM\OFF\Microsoft\Windows\CurrentVersion\Authentication\Credential Providers\{7C4E1A62-9D3B-4F58-A1E7-5B2C8D94F013}" /f
                 reg delete "HKLM\OFF\Classes\CLSID\{7C4E1A62-9D3B-4F58-A1E7-5B2C8D94F013}" /f
                 reg unload HKLM\OFF
          4. 重启，锁屏就回到 Windows 原样。
        （如果 dir 显示 Windows 不在 C:，把上面的 C: 换成实际盘符。）

    [D] 不会发生的事（说清楚，免得你担心）
        * 不会把你的账户锁死：每次自动提交密码之前，程序都会先用 Windows
          真登一次验证；一旦发现库里存的密码已经登录不了（比如你改过密码），
          它就【一次都不再提交】，并写清楚原因到日志。
          这条很关键 —— 本机策略是"10 次密码错锁 10 分钟"，如果它闷头乱提交，
          你反而会被自己的程序锁在门外。
        * 常驻程序不在、凭据读不出来时，凭据提供者会立刻"什么凭据都不枚举" ——
          锁屏上你看到的就是 Windows 原样，手输密码不受任何影响。
        * 卸载会先注销凭据提供者再删文件（顺序反了才会把锁屏弄坏）。


安全性说明（请知悉）
    * 声纹是【生物特征】，泄露不可撤销。本程序不联网、不上传任何音频。
    * 判定只看声纹，不做语音识别，你说什么内容不影响结果。
    * 声纹只当"便捷因素"。任何能在你已解锁的桌面上运行程序的人，
      本来就能读到你的一切 —— 声纹解锁不改变这一点。
